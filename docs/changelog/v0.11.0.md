## 更新内容

- 去除应用图标蒙版（设置与桌面，可选包含动态图标）
- 锁屏时钟颜色自定义
- UDS 实时连接引擎：禁用固件自动下载、禁用自动安装、禁用预装应用自动更新
- UDS 实时连接引擎：禁用 UPS 推送、禁用数据上报
- UDS 实时连接引擎：本地安装包重签（需先安装 OTA 证书信任模块）
- OTA 请求伪装迁移到 UDS 引擎页面
- ZUI 性能服务：屏蔽省电策略云端同步、屏蔽游戏策略 OTA 下发
- 媒体输出磁贴与弹窗居中
- 充电动画时长自定义
- 网速指示器隐藏慢速
- 禁止游戏中降亮度（禁用高温降低亮度）
- 大文件夹对齐（正方形大文件夹）
- 无字模式，抽屉和桌面各自拦截
- 启动器内批量卸载 APP
- 热重载功能修复，自动热重载可用
- DexKit 离线索引，集中管理 DexKit 查找的方法名（Hook 侧不再调用原生库）
- 支持清除受污染的持久化值
- 更新完美横屏适配（已适配应用策略扩充至 3111 个）
- 补全 Credits: 一言支持、GitHub 加速支持
