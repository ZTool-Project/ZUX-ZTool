# v0.8.0

> 旧版本标识：`Beta/260624`（构建计数 `c791`）；Git 标签 `20260624-ZTool_Beta`。

## 更新内容

- 音量/亮度条百分比显示
- 在设置内显示快捷跳转入口
- 根据实际安装的应用展示功能入口
- 检测非 ZUXOS/ZUI 设备
- 新的 First Run 界面
- (测试) 允许不受信任的触摸
- (测试) 禁止人脸识别超时
- 自定义关于设备面板中的一些信息
- 去除原生安装器的“此应用未经《联想终端质量检测和安全审查标准》审核，建议使用官方“应用中心”安装经过检测的应用。”警告
- 控制中心磁贴无字模式
- 控制中心透明度自定义
- 控制中心磁贴颜色自定义
- 控制中心磁贴圆角半径自定义
- 关闭新版本系统可用的小红点提示
- 最近任务显示内存信息
- 净化全局搜索
- 增强阻止安全中心扫描功能，现在可以阻止其它类型的一些安全扫描，例如安全中心内手动触发的扫描功能，并阻止病毒警报弹窗
- 添加亮灭屏过渡动画功能
- 支持在应用信息字段显示更多内容，例如 Target SDK ，并支持长按复制到剪贴板
- Compose 重构，更规范的 Material 3 (Expressive) 主题，并支持 miuix 作为替代主题
- 修复 Android 16 禁止处理游戏音频问题
- 修复一视界拓展模块只能在 ZTool 内安装和卸载的问题
- 修复从 ZTool 安装的一视界拓展模块可能无法正确生效的问题
